# The One with Me 🤖

**Your Personal AI Study & Mental Health Buddy**

## Overview
A Flask-based web chatbot powered by Claude AI. Get study help, talk about stress, find motivation, or just chat with your friendly AI assistant.

## Features ✨
- 💬 **Friendly Conversations** - Natural, casual chat with emojis
- 📚 **Study Help** - Homework assistance, concept explanations
- 🧠 **Mental Health Support** - Stress management, motivation
- 🌙 **Dark Theme UI** - Beautiful, easy-on-the-eyes interface
- 🚀 **Always Available** - 24/7 support whenever you need it

## Tech Stack 🛠️
- **Backend:** Flask (Python)
- **AI Engine:** Claude API (Anthropic)
- **Frontend:** HTML5, CSS3
- **Deployment:** Replit

## Installation 📦

### Requirements
- Python 3.8+
- pip (Python package manager)

### Setup
1. Clone this repository
```bash
git clone https://github.com/harishatithya/the-one-with-me.git
cd the-one-with-me
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Create `.env` file with your Claude API key
ANTHROPIC_API_KEY=your_api_key_here

4. Run the app
```bash
python app.py
```

5. Open browser and go to `http://localhost:5000`

## How to Use 💡
1. Type your message in the input box
2. Click "Send" or press Enter
3. Get instant AI responses
4. Use "New Chat" to start fresh conversations
5. Use "Clear Chat" to reset messages
